# UIVerse
UIVerse is a modern SwiftUI-based authentication app featuring a clean and elegant user interface. It includes a beautifully designed onboarding screen, login,forgot password and sign-up flow with smooth navigation and responsive layouts. Built using SwiftUI’s declarative approach, this project demonstrates best practices for UI design, state management, and user experience in iOS development.
